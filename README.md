# پلنر مطالعه – ساختار پروژه

این مخزن نسخهٔ PWA برنامه‌ریز مطالعه است و برای Cloudflare Pages آماده شده است.

## اجزای برنامه
- `index.html`: پوستهٔ HTML و ترتیب بارگذاری منابع.
- `app.css`: استایل اصلی رابط کاربری؛ `analytics.css` استایل بخش تحلیل.
- `analytics-engine.js`: محاسبهٔ مستقل شاخص بازدهی و تست‌های داخلی فرمول.
- `app-core.js`: تاریخ، مدل داده، اعتبارسنجی، ذخیره‌سازی، تایمر و همگام‌سازی.
- `app-views.js`: تولید رابط صفحات و کارت‌ها.
- `app-actions.js`: عملیات کاربر و تغییر وضعیت برنامه.
- `app-events.js`: رویدادهای مرورگر، شروع برنامه و اتصال تعامل‌ها.
- `pwa-update.js` و `sw.js`: به‌روزرسانی PWA و کش آفلاین.
- `functions/api/backup.js`: API بکاپ رمزگذاری‌شده با KV.
- `tests/`: تست موتور شاخص، ساختار برنامه و API بکاپ.

## داده‌ها و ایمنی
اطلاعات برنامه، درس‌ها، پارت‌ها و زمان‌های مطالعه در فضای محلی مرورگر ذخیره می‌شوند. تصویر پس‌زمینهٔ تایمر در IndexedDB نگهداری می‌شود و نسخهٔ پشتیبان محلی نیز ساخته می‌شود. بکاپ ابری در مرورگر با کلید مشتق‌شده از کد بازیابی رمزگذاری می‌شود. شناسه و binding فضای KV باید حفظ شود.

ویرایش برنامهٔ تکرارشونده نباید لاگ تکمیل روزهای گذشته را دوباره محاسبه کند. امتیاز تاریخی فقط زمانی معتبر است که تصویر ثابت برنامهٔ همان روز وجود داشته باشد؛ برنامه از ساخت امتیاز با حدس‌زدن الگوی فعلی برای گذشته خودداری می‌کند.

در استقرارهای Preview، API بکاپ بر اساس hostname درخواست را مسدود می‌کند؛ حتی در صورت به‌ارث‌رسیدن binding فضای KV، نسخهٔ آزمایشی نمی‌تواند بکاپ Production را بخواند یا تغییر دهد. بکاپ ابری فقط در دامنهٔ Production فعال است.

## آزمون
با Node.js 20 یا جدیدتر:
`node tests/analytics-engine.test.mjs`
`node tests/backup-api.test.mjs`

فایل‌های اجرایی بدون bundler و به‌ترتیب مشخص در `index.html` بارگذاری می‌شوند. پس از افزودن فایل اجرایی جدید، آن را به فهرست `CORE` در `sw.js` و تست ساختار در `tests/analytics-engine.test.mjs` اضافه کن.

## انتشار
توسعه و اصلاحات فعلی روی شاخهٔ `analytics-engine-v1` انجام می‌شوند. شاخهٔ `main` و نسخهٔ تولیدی جدا هستند؛ انتشار آزمایشی نباید با ادغام یا تغییر شاخهٔ اصلی جایگزین شود.
